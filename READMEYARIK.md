- НЕЛЬЗЯ!!! Если будет добавлена новая запись или просто новый код грнти, нужно будет найти соответствующее название предмета, 
которого до этого могло и не быть, а в grntirub есть все. Оставляем 3 таблицы. И мысль тут оставляю, чтобы больше в голову не приходила.

Проблема, что в grnti где-то разделитель запятая, где-то точка с запятой, где-то пробел, а еще бывает,
что не три числа идут через точку, а только две. Формат, я думаю, должен быть xx.xx.xx, xx.xx.xx чтобы не видоизменять при выводе на экран. Где 2 числа оставляем тоже,
когда не два и не три или не через точку сам код написан, предупреждаем, что код грнти неправильный и заносим, например, пустое поле, чтобы потом в самом приложении можно было исправить.

Обработка кодов грнти, вроде на наших всех пашет
```c#
partial class Program
{
    public static void Main()
    {
        Console.Write("Введи код урод: ");
        string? codestring = Console.ReadLine();
        if (codestring != null)
        {
            codestring = codestring.Trim();
            string[] codes = codestring.Split(new[] { ",", ";", " " }, StringSplitOptions.None);

            for (int i = 0; i < codes.Length; i++)
            {
                codes[i] = codes[i].Trim();
                if (!(Regex.IsMatch(codes[i], @"^\d{2}\.\d{2}\.\d{2}$") || Regex.IsMatch(codes[i], @"^\d{2}\.\d{2}$") || Regex.IsMatch(codes[i], @"^\d{2}$")))
                {
                    Console.WriteLine($"Не понял");
                    return;
                }
            }
            string coderesult = string.Join(", ", codes);
            Console.WriteLine($"Понял, значит {coderesult}");
            return;
        }
        Console.WriteLine($"Ну громче");
    }
}
```
